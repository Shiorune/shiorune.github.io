# Shiorune（シオルネ）

小説をスマートフォンやパソコンで読むためのWebリーダーです。フォントや背景を好みに合わせ、読書の続きを楽しめます。

**[Shioruneで読む](https://shiorune.github.io/)**

## 使い方

1. 作品一覧から小説を選びます。
2. エピソード一覧から話を選びます。本文の上部からも目次を開けます。
3. 上部の「Aa」からフォント・背景色・文字サイズ・行間を調整できます。
4. 読書位置はブラウザに保存され、作品ページから続きを開けます。

## 主な機能

- エピソード一覧、読書位置の保存、未読・読書中・読了の進捗表示
- 作品ごとの読書状況リセット
- 8種類のフォント、14種類の背景色と自由なカラー設定
- 文字サイズ・行間の調整
- 閲覧した話の自動保存、作品ごとの「全話を保存」によるオフライン読書

## オフラインで読む

オンラインで作品のエピソード一覧を開き、「オフライン保存」を展開して「全話を保存」を選びます。保存した話は、対応するブラウザでオフラインでも読めます。

保存データは端末やブラウザの設定によって削除されることがあります。外出前に、通信を切った状態で読めるか確認してください。

## 表示について

利用できる書体は端末によって異なり、選択した書体がない場合は代替フォントで表示されます。
